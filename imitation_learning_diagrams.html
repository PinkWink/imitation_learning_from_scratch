4) ACT Model Internals (Training + Inference)

CNN encoder + fixed sinusoidal positional encoding + transformer + action head.

flowchart LR subgraph Input["Input Sequence"] A["x_seq: [B,T,3,84,84]"] end subgraph Enc["Per-frame Encoder"] B["Conv(3->6,k5)+ReLU+AvgPool"] C["Conv(6->16,k5)+ReLU+AvgPool"] D["Flatten + Linear -> hidden(128)"] end subgraph Pos["Temporal Tokens"] E["Stack frame features -> [B,T,D]"] F["Add fixed sinusoidal pos_embed"] G["LayerNorm"] end subgraph Tf["Transformer Encoder x3"] H["MHSA + FFN (gelu)"] end subgraph Head["Action Head"] I["Linear 128->64 + ReLU"] J["Linear 64->2 + Tanh"] K["pred_seq: [B,T,2]"] end A --> B --> C --> D --> E --> F --> G --> H --> I --> J --> K K --> L["Train: MSE(pred_seq, y_seq)"] K --> M["Infer: use last step pred_seq[:, -1, :]"]
